## Branching Strategy

Ex:

```md
This repository employs a Release Branching strategy. A new release branch will be created at the beginning of the sprint and feature branches will be merged to the release branch during the sprint. At the end of the sprint the latest release branch will be released to production and the release branch changes will be merged to main.
```
